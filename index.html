Troubleshooting guides

Each guide follows the same support process: understand the problem, ask the right questions, check in order from simplest to most complex, fix it, and document it.

1. Wi-Fi won't connect

Problem: A user cannot connect to Wi-Fi, or keeps dropping off the network.

Symptoms: No internet, Wi-Fi icon shows limited connection, or only one device is affected.

What to ask the user: Is it just your device, or everyone? Did it work before? What changed — new password, new router, moved desks?

Checks in order:

  1. Check Wi-Fi is turned on, airplane mode is off, and the correct network is selected.
  2. Forget the network and reconnect, typing the password carefully.
  3. Restart the device, then restart the router / access point if the whole area is down.
  4. Check if other devices work, to find out if it is a device problem or a network problem.
  5. Check IP settings, run the network troubleshooter, and update the Wi-Fi driver if needed.
  6. Escalate to network support if the access point, switch, or internet service is down.

Solution & follow-up: Reconnect the user, test a website and an internal system, and document the device, network name, and fix in the ticket.

2. Printer shows offline

Problem: A user tries to print, but the printer shows as offline.

Symptoms: Print jobs sit in the queue, or the printer is not listed.

What to ask the user: Which printer? Is it just you, or the whole office? Did you print to it before?

Checks in order:

  1. Check the printer is turned on, has paper and ink, and shows no error lights.
  2. Check the cable or Wi-Fi connection, and that the printer is on the same network.
  3. On the computer, check that the correct printer is set as default.
  4. Clear stuck jobs from the print queue and restart the print spooler service if needed.
  5. Remove and reinstall the printer driver if the printer still does not respond.
  6. Escalate if it is a network printer issue affecting many users.

Solution & follow-up: Print a test page, confirm with the user, and note the printer name and fix in the ticket.

3. Account locked / password reset

Problem: A user cannot sign in because the account is locked or they forgot their password.

Symptoms: "Incorrect password", account locked message, or multi-factor prompt not working.

What to ask the user: Are you using the right username and system? Did you recently change your password? Are you locked out of one system or all systems?

Checks in order:

  1. Verify the user's identity following company policy. Never share or ask for someone else's password.
  2. Check Caps Lock, keyboard layout, and that they are on the correct sign-in page.
  3. Unlock the account or reset the password through the approved admin tool.
  4. Ask the user to sign in while you are with them, and help them set up multi-factor authentication if needed.
  5. Check if the issue affects email, VPN, or other systems, and fix access in each system.

Solution & follow-up: Confirm the user can sign in, remind them not to share passwords, and document the reset following security policy.

4. Computer is very slow

Problem: A computer takes a long time to start, open programs, or respond.

Symptoms: Freezing, fan running loudly, disk or memory very high in Task Manager.

What to ask the user: When did it start? Is it slow for one program or everything? Have you installed anything new?

Checks in order:

  1. Restart the computer and close programs the user does not need.
  2. Check Task Manager for programs using a lot of CPU, memory, or disk.
  3. Check storage space, run updates, and remove temporary files safely.
  4. Check for too many startup programs and turn off the ones not needed.
  5. Run a security scan and check for failing hardware signs, like strange noises or repeated crashes.
  6. Escalate for a hardware check or upgrade if the slowness continues after these steps.

Solution & follow-up: Test the programs the user actually uses, explain what changed, and document the fix.

5. Email won't sync

Problem: A user is not receiving new emails, or sent emails are stuck.

Symptoms: Inbox stops updating, sync errors, or emails only arrive on one device.

What to ask the user: Is it email on your phone, computer, or webmail? When did you last get an email? Did you change your password recently?

Checks in order:

  1. Check internet connection and that the user is signed in to the correct account.
  2. Check storage quota — a full mailbox can stop new mail from arriving.
  3. Check sync settings, and that the app is set to fetch new mail automatically.
  4. Sign out and sign back in, or remove and re-add the account in the mail app if needed.
  5. Check webmail: if webmail works, the problem is in the app or device settings.
  6. Escalate to email administration if mail is delayed for many users.

Solution & follow-up: Send a test email, confirm it arrives, and document the account and fix.

How I work a ticket

  1. Listen: What is the user trying to do, and what exactly is happening?
  2. Reproduce: Can I see the problem, or is it only on one device?
  3. Check simply first: Power, cables, Wi-Fi, correct account, correct printer.
  4. Fix and test: Fix it, then test with the user, not just on my own.
  5. Document: Write down what was wrong and what fixed it, so the next technician does not start from zero.
